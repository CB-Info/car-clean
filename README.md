# CarClean · site vitrine

Stack : Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion (LazyMotion) · Lenis. Animations décoratives en CSS pur, jouées une seule fois.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # build de production dans dist/
```

- **Contenu, tarifs, contacts, images** : `src/data/content.ts`
- **Calcul du prix** (formule + options + déplacement) : `src/lib/pricing.ts`
- **Sections** : `src/components/sections/`
- **Composants animés (style Magic UI)** : `src/components/magicui/`

Déploiement : `dist/` est statique, compatible Vercel, Netlify ou Cloudflare Pages.
